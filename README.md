# Chennai House Price Prediction!

In this project, I worked on a dataset of Chennai real estate to predict house prices using Machine Learning regression models.

🔍 Key Steps:
✅ Data Processing & Cleaning
✅ Exploratory Data Analysis (EDA) & Statistical insights
✅ Feature Selection & Encoding
✅ ML Regression Models for Price Prediction

📊 This project helped me understand how different features impact house pricing and how regression techniques can be applied to real-world problems.
